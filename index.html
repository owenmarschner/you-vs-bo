Instructions

BO assumptions

  • Objective. One continuous input between 0 and 1. Each evaluation returns the exact function value, with no measurement noise.
  • Surrogate model. A Gaussian process with zero prior mean and a squared-exponential kernel. The fixed length scale of 0.15 controls how quickly correlation decreases with distance. The prior standard deviation is 200 in function-value units.
  • Selection rule. Expected improvement estimates the average positive gain over BO’s best observed value under the current model. BO chooses the highest EI among 2,001 evenly spaced candidates, excluding its previous inputs, and evaluates one point per turn.
  • Replay. The shaded region is a pointwise 95% posterior interval under the model. The interval applies to each input individually.
